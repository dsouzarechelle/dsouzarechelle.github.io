
# My Personal Website - GitHub Pages

## Project Description
This project is a simple, responsive static website created using HTML and CSS. It is hosted for free using GitHub Pages.

## Objectives
- Create a static website using HTML and CSS.
- Deploy the website using GitHub Pages.
- Learn basic website hosting and deployment.

## Technologies Used
- HTML5
- CSS3
- GitHub
- GitHub Pages

## Features
- Clean and modern design
- Responsive layout for mobile devices
- About section describing the project
- Technologies section
- Link to my GitHub profile

## Deployment Steps
1. Created a public GitHub repository.
2. Added the HTML, CSS, and README files.
3. Opened repository Settings.
4. Selected Pages under Code and automation.
5. Selected the `main` branch and root folder.
6. Saved the settings and waited for deployment.

Learned how to create a static website and publish it online for free using GitHub Pages.
